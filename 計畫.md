## Where things stand

The jianpu line is complete end to end: key detection → lyrics and timeline → note values →
intonation scoring → note-value symbols, time signature and barlines in the main view.
The evaluation harness measures five metrics in one pass, and the training-free knob sweep
and the Taiwanese LoRA A/B have both been run on real data.

| Done | Location |

## A. Evaluation — 3 of 5 metrics measured, 2 blocked on data

Hallucination rate, alignment error and the speech regression set never appear in a report
because the inputs do not exist yet. The harness names each unmeasured metric and why, so
this is visible rather than silent.

| Missing input | How to supply it |
|---|---|
| **C-layer negative audio** | Rebuild songs with accompaniment using `--negative_ratio` (default 0.08): `build_lyric_dataset.py … --source_type youtube/local`. A cappella and read-speech corpora produce no negatives (`is_mix=False`) — that is deliberate |
| **`speech_`-prefixed regression set** | 20 meeting recordings ingested with `--source_type local`; the id must start with `speech_` |
| **Hand-annotated timings** | Add `words: [{word, start, end}]` to the rows you care about in `dataset/manifests/*.jsonl`; unannotated clips are excluded from alignment error and the report says so |

```
.venv/Scripts/python.exe tools/eval_asr.py \
    --model models/breeze-asr-25-ct2 --sources nan,mir1k,negative,speech --tag breeze_baseline
```

Acceptance: all five numbers present, and one report each for the stock preset and the
Taiwanese LoRA so they can be compared.

## B. Training-free knobs — mostly swept, three left

Swept and settled (see `dataset/eval_reports/sweep_*`): `beam_size=5` is the only real gain
and has shipped for file mode; `temperature` fallback, `compression_ratio_threshold` and
`condition_on_previous_text` do nothing on clean sung clips; `vad_filter` shreds singing and
stays off; a Chinese `initial_prompt` helps Mandarin and hurts English, so it is not a
default; `int8_float16` is not worth the accuracy loss.

Still unswept:

- **Force Demucs on, and compare `htdemucs` vs `htdemucs_ft`.** Requires changing
  `transcribe_one`.
- **Re-sweep `no_speech_prob` / RMS thresholds against separated vocals.** The current
  0.6 / 0.02 were tuned for speech. Already wired as `--no-speech-threshold` /
  `--rms-threshold`, so this needs no code change.
- **beam 5 on the batch path.** The sweep ran on single-pass `WhisperModel.transcribe`, but
  `POST /api/transcribe/file` uses `BatchedInferencePipeline` with its own internal VAD —
  and VAD is exactly what hurt singing. Re-run the A/B on the batch path before trusting the
  default.

  kept. A second round needs more English singing data; do not spend time on
  hyperparameters.
- **Ingest CV zh-TW** and mix 5 % as anti-forgetting replay
  (`--dataset_name common_voice --target_lang zh-TW`).
- **Taiwanese songs via YouTube + LRC** → a second Taiwanese singing LoRA
  (`--source_type youtube --lyrics *.lrc --target_lang nan`). The current Taiwanese LoRA was
  trained on Common Voice **read speech**; the only singing data is MIR-1K Mandarin. This
  round also produces the C-layer negatives that A needs.

## D. Music analysis polish

- **Time-signature refinement.** Only 2/3/4 are considered, and `_beat_phase` finds beat
  phase rather than the downbeat (patched with `downbeat_offset`). Real accuracy needs
  bar-level autocorrelation or harmonic change points. The stats row honestly shows "?" when
  the meter is assumed rather than measured.
- **Fast songs may report half tempo** (the prior favours solutions near 120 BPM). This is
  deliberate, but the UI should offer a manual ×2 / ÷2 correction.
- **Live per-utterance tonic jumps** — each utterance is estimated independently, and only
  post-processing has a global tonic. Accumulating a session-level pitch histogram in
  `StreamState` would fix it.
- **Lyric alignment interpolates evenly when a whole line is missed** (`anchoredRatio` flags
  it). The refinement is per-token forced alignment via ctranslate2 `Whisper.align`
  (confirmed present in 4.7.2; faster-whisper also exposes `find_alignment`), which would
  also give A's alignment error a second reference.
- **Intonation cannot detect wrong notes** — there is no reference melody, and with
  accompaniment it cannot match the backing track's tuning. Doing this needs a melody source
  other than lyric alignment.
